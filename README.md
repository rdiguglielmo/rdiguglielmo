## About

I work on the whole path a number travels: pulling it out of a public source that was never
designed for analysis, modelling it so it can be aggregated without lying, checking it, and
putting it in front of someone who has to decide something.

This portfolio is being built in the open, one project at a time. **One of the four below is
complete**; the rest are listed with what they will demonstrate, because writing that down before
building forces the scope to be honest.
